# Файли каталогу

Покладіть сюди JAR (можна в підпапки). Бінарні ігри ігноруються Git і Docker: вони не публікуються у вихідному коді.

Після запуску магазину відкрийте «Магазин → Адміністрування», увійдіть і виберіть кілька JAR або папку. Нові ігри створюються як чернетки. Перевірте назву, жанр, розмір екрана та опублікуйте потрібні ігри. JAR залишається незмінним; опис зберігається в серверному каталозі.

Резервна копія сервера має містити весь том repository-data, включно з catalog.json, jars/, icons/ та auth.json. Пароль — у приватному admin-credentials.txt; не завантажуйте його в GitHub.
